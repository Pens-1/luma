## Phase 1: The Scheduler（数理的スケジュール最適化）

### 概要

毎朝自動で最適なスケジュールを計算し、カレンダーに登録して Discord で通知。

### フロー図

```mermaid
sequenceDiagram
    participant cron as ⏰ Cron (毎朝7:00)
    participant n8n as n8n
    participant gcal as Google Calendar
    participant notion as Notion
    participant fastapi as FastAPI (OR-Tools)
    participant discord as Discord

    cron->>n8n: トリガー発火

    par 並列取得
        n8n->>gcal: 今日の確定予定を取得
        gcal-->>n8n: 予定リスト
    and
        n8n->>notion: 未完了タスクを取得
        notion-->>n8n: タスクリスト（優先度/所要時間/期限）
    end

    n8n->>fastapi: POST /api/v1/optimize/schedule
    Note over fastapi: OR-Toolsで最適化計算<br/>・タスクの優先度<br/>・所要時間<br/>・期限<br/>・既存予定との衝突回避
    fastapi-->>n8n: 最適化されたスケジュール

    loop 各タスクを登録
        n8n->>gcal: 予定を作成
    end

    n8n->>discord: 📋 今日の戦略ブリーフィング
    Note over discord: • 本日の予定一覧<br/>• 重要タスクのハイライト<br/>• 推定完了時刻
```

### n8n ワークフロー構成

```
[Schedule Trigger: 毎朝7:00]
    ↓
[HTTP Request: GCal API - 今日の予定取得]
    ↓
[HTTP Request: Notion API - 未完了タスク取得]
    ↓
[Merge: データ統合]
    ↓
[HTTP Request: FastAPI /optimize/schedule]
    ↓
[Loop: 最適化結果をGCalに登録]
    ↓
[Discord: ブリーフィング送信]
```

### FastAPI エンドポイント

```
POST /api/v1/optimize/schedule

Request:
{
  "fixed_events": [...],      // GCalから取得した確定予定
  "tasks": [                  // Notionから取得したタスク
    {
      "id": "task-1",
      "title": "設計レビュー",
      "priority": 1,          // 1=高, 2=中, 3=低
      "duration_minutes": 60,
      "deadline": "2024-12-12T18:00:00"
    }
  ],
  "work_start": "09:00",
  "work_end": "22:00"
}

Response:
{
  "schedule": [
    {
      "task_id": "task-1",
      "start": "2024-12-12T09:00:00",
      "end": "2024-12-12T10:00:00"
    }
  ],
  "unscheduled": [],          // スケジュールできなかったタスク
  "summary": "5件のタスクを配置しました"
}
```

## Phase 2: The Knowledge Brain（知識統合と RAG）

### 概要

Notion の技術メモ・設計書を知識ベースに同期し、チャットで質問できるようにする。

### フロー図

```mermaid
sequenceDiagram
    participant user as 👤 ユーザー
    participant dify as Dify Chat
    participant kb as Dify Knowledge Base
    participant weaviate as Weaviate (Vector DB)
    participant notion as Notion
    participant n8n as n8n

    Note over n8n,notion: === 知識同期フロー（定期実行） ===
    n8n->>notion: 更新されたページを取得
    notion-->>n8n: ページコンテンツ
    n8n->>dify: Knowledge Base API で同期
    dify->>weaviate: ベクトル化して保存

    Note over user,dify: === 質問応答フロー ===
    user->>dify: 「〇〇の設計方針は？」
    dify->>weaviate: 類似ドキュメント検索
    weaviate-->>dify: 関連ドキュメント
    dify->>dify: LLMで回答生成
    dify-->>user: 過去の記録に基づいた回答
```

### RSS 収集・要約フロー

```mermaid
sequenceDiagram
    participant rss as RSS (Zenn/HN)
    participant n8n as n8n
    participant dify as Dify (AI判断)
    participant notion as Notion 積読DB
    participant discord as Discord

    n8n->>rss: 新着記事をフェッチ
    rss-->>n8n: 記事リスト

    loop 各記事
        n8n->>dify: 興味判定 + 3行要約
        Note over dify: ユーザーの興味タグと照合<br/>関連度スコア算出
        dify-->>n8n: {関連度: 0.8, 要約: "..."}

        alt 関連度 > 0.6
            n8n->>notion: 積読DBに追加
        end
    end

    n8n->>discord: 📚 今日の厳選記事 (3件)
```

## Phase 3: Real World Interface（情報収集と通知）

### 大学ポータル監視フロー

```mermaid
sequenceDiagram
    participant cron as ⏰ Cron (1時間毎)
    participant n8n as n8n
    participant fastapi as FastAPI (Playwright)
    participant portal as 大学ポータル
    participant dify as Dify (重要度判定)
    participant discord as Discord

    cron->>n8n: トリガー発火
    n8n->>fastapi: POST /api/v1/scrape/portal

    fastapi->>portal: ヘッドレスブラウザでログイン
    portal-->>fastapi: お知らせ一覧HTML
    Note over fastapi: HTMLパース<br/>前回との差分検出
    fastapi-->>n8n: 新着お知らせリスト

    alt 新着あり
        n8n->>dify: 重要度判定
        Note over dify: 休講/試験/締切 = 重要<br/>その他 = 通常
        dify-->>n8n: {重要度: "high", 理由: "休講情報"}

        alt 重要度 = high
            n8n->>discord: 🚨 緊急通知
        else
            n8n->>notion: 通常お知らせDBに保存
        end
    end
```

### スマート・インボックス（メール監視）フロー

```mermaid
sequenceDiagram
    participant gmail as Gmail
    participant n8n as n8n
    participant dify as Dify (AI分類)
    participant discord as Discord
    participant notion as Notion 朝刊DB

    gmail->>n8n: 新着メール (Webhook/Polling)
    n8n->>dify: メール分類リクエスト

    Note over dify: 分類ロジック:<br/>1. サーバーアラート → 即通知<br/>2. VIP送信者 → 即通知<br/>3. 重要キーワード → 即通知<br/>4. その他 → 朝刊

    dify-->>n8n: {category: "alert", urgency: "high"}

    alt 即通知カテゴリ
        n8n->>discord: 📧 重要メール通知
    else 朝刊カテゴリ
        n8n->>notion: 朝刊DBに蓄積
    end

    Note over n8n: 毎朝8:00に朝刊配信
    n8n->>discord: 📰 本日の朝刊（昨日のメール要約）
```

## API エンドポイント一覧

### FastAPI (localhost:8001)

| エンドポイント              | メソッド | 機能                       |
| --------------------------- | -------- | -------------------------- |
| `/api/v1/optimize/schedule` | POST     | スケジュール最適化         |
| `/api/v1/scrape/portal`     | POST     | 大学ポータルスクレイピング |
| `/health`                   | GET      | ヘルスチェック             |

### Dify (localhost:80)

| 機能           | 用途                             |
| -------------- | -------------------------------- |
| Knowledge Base | Notion 同期、RAG 検索            |
| Workflow       | 記事要約、メール分類、重要度判定 |
| Chat App       | 知識ベースへの質問応答           |

### n8n (localhost:5678)

| ワークフロー      | トリガー       | 機能               |
| ----------------- | -------------- | ------------------ |
| Morning Scheduler | Cron 7:00      | スケジュール最適化 |
| RSS Collector     | Cron 6:00      | 技術記事収集       |
| Portal Monitor    | Cron 毎時      | 大学ポータル監視   |
| Email Inbox       | Polling 5 分毎 | メール監視         |
| Morning Briefing  | Cron 8:00      | 朝刊配信           |
